## 🎯 Deploy em 3 Passos

### 1. Push para o GitHub

```bash
# Inicialize o git (se ainda não fez)
git init
git add .
git commit -m "CV Builder - Pronto para deploy"

# Adicione o remote
git remote add origin https://github.com/SEU_USUARIO/cv-builder.git

# Push
git branch -M main
git push -u origin main
```

### 2. Deploy na Vercel

1. Acesse: **https://vercel.com/new**
2. Importe o repositório `cv-builder`
3. Clique em **"Deploy"**
4. Aguarde 2-3 minutos
5. ✅ Pronto!

### 3. Acessar o Site

- **Landing Page**: `https://seu-projeto.vercel.app/`
- **Builder**: `https://seu-projeto.vercel.app/#/builder`

---

## 🔑 Configurar IA (Opcional)

Se quiser usar a IA:

1. Obtenha API Key: https://openrouter.ai/keys
2. Na Vercel: **Settings** → **Environment Variables**
3. Adicione:
   - **Name**: `VITE_OPENROUTER_API_KEY`
   - **Value**: `sk-or-v1-sua-chave-aqui`
4. Clique em **Save**
5. Faça **Redeploy**

## 🐛 Se Houver Problemas

### Página em Branco?

1. **Use URLs com hash**: `/#/builder` (não `/builder`)
2. **Limpe o cache**: Ctrl+Shift+R
3. **Verifique o console**: F12 → Console
4. **Tente modo anônimo**

### Build Falha?

1. Teste localmente: `npm run build`
2. Verifique os logs na Vercel
3. Corrija os erros
4. Commit e push
