# 🤖 Guia de Integração com IA - OpenRouter

## 📋 Configuração Inicial

### 1. Obter API Key Gratuita

1. Acesse: https://openrouter.ai/keys
2. Faça login com sua conta Google ou GitHub
3. Clique em "Create Key"
4. Dê um nome para a chave (ex: "CV Builder")
5. Copie a chave gerada (sk-or-v1-...)

### 2. Configurar no CV Builder

1. Abra o CV Builder
2. Clique em "Baixar PDF"
3. No modal, clique em "Sugestões de IA"
4. Clique em "Configurar API Key"
5. Cole sua API Key
6. Selecione o modelo desejado
7. Clique em "Salvar"

✅ Pronto! A IA está configurada e pronta para uso.

## 🎯 Funcionalidades de IA

### 1. Sugestões de Melhoria

**O que faz:**
- Analisa seu currículo completo
- Identifica pontos fracos
- Sugere melhorias específicas
- Avalia confiança de cada sugestão

**Como usar:**
1. Preencha seu currículo
2. Clique em "Sugestões de IA"
3. Aguarde a análise (5-10 segundos)
4. Veja as sugestões com ícones e cores

**Tipos de sugestões:**
- 📝 Resumo Profissional
- 💼 Experiência
- 🎯 Skills
- 💡 Melhorias gerais

### 2. Gerador de Carta de Apresentação

**O que faz:**
- Gera carta personalizada para vaga específica
- Adapta tom (formal/casual/entusiasta)
- Conecta suas experiências com requisitos da vaga
- Otimiza para ATS

**Como usar:**
1. Clique em "Carta de Apresentação"
2. Cole a descrição da vaga
3. Escolha o tom desejado
4. Selecione o modelo de IA
5. Clique em "Gerar Carta"
6. Copie ou baixe como TXT

**Dicas:**
- Use descrições completas da vaga
- Inclua requisitos e responsabilidades
- Experimente diferentes tons
- Revise e personalize antes de enviar

### 3. Melhorar Descrição de Experiência

**O que faz:**
- Reescreve descrições de forma mais impactante
- Adiciona verbos de ação
- Quantifica resultados
- Otimiza para ATS

**Como usar:**
1. Vá em "Experiência"
2. Clique em "Melhorar com IA" ao lado da descrição
3. Aguarde a sugestão
4. Aceite ou edite manualmente

## 🔒 Privacidade e Segurança

### Onde os dados são processados?
- ✅ API da OpenRouter (servidores seguros)
- ❌ Não enviamos para nossos servidores
- ❌ Não armazenamos suas informações

### O que é enviado para a IA?
- Dados do currículo (texto)
- Descrição da vaga (texto)
- ❌ Fotos não são enviadas
- ❌ Dados pessoais sensíveis (CPF, RG) não são enviados

### Como proteger sua API Key?
- ✅ Salva apenas no seu navegador (localStorage)
- ✅ Nunca é enviada para nossos servidores
- ⚠️ Não compartilhe sua API Key
- ⚠️ Se comprometida, gere uma nova na OpenRouter

## 💡 Dicas de Uso

### Para Melhores Resultados

1. **Preencha o máximo possível**
   - Quanto mais dados, melhor a análise
   - Inclua todas as experiências relevantes
   - Liste skills técnicas e comportamentais

2. **Seja específico**
   - Use métricas e números
   - Descreva responsabilidades claras
   - Inclua conquistas mensuráveis

3. **Revise as sugestões**
   - IA é uma ferramenta, não substitui julgamento humano
   - Adapte sugestões ao seu estilo
   - Mantenha autenticidade

4. **Teste diferentes modelos**
   - GPT-4: Melhor qualidade, mais caro
   - Claude 3: Excelente para escrita criativa
   - Llama 3: Gratuito e rápido
   - Mistral: Bom custo-benefício

5. **Experimente diferentes tons**
   - Formal: empresas tradicionais
   - Casual: startups, empresas jovens
   - Entusiasta: vagas criativas, marketing

### Limitações da IA

- ❌ Não conhece o mercado específico
- ❌ Não substitui revisão humana
- ❌ Pode gerar sugestões genéricas
- ❌ Não garante aprovação em vagas

### Quando NÃO usar IA

- Vagas muito específicas/técnicas
- Quando precisa de conhecimento local
- Para indústrias regulamentadas
- Quando a vaga pede "sem uso de IA"

## 🆘 Solução de Problemas

### "API Key inválida"
- Verifique se copiou a chave completa (sk-or-v1-...)
- Confirme que a chave está ativa na OpenRouter
- Gere uma nova chave se necessário

### "Erro ao gerar sugestões"
- Verifique conexão com internet
- Confirme que tem créditos (para modelos pagos)
- Tente outro modelo (ex: Llama 3 8B gratuito)

### "Sugestões muito genéricas"
- Preencha mais detalhes do currículo
- Seja específico nas experiências
- Inclua mais skills e projetos
- Tente modelo mais avançado (GPT-4, Claude 3)

### "Carta não reflete a vaga"
- Cole descrição completa da vaga
- Inclua requisitos específicos
- Tente tom diferente
- Use modelo mais avançado

### "Modelo muito lento"
- Use modelos mais rápidos (Llama 3 8B, Mistral 7B)
- Verifique conexão com internet
- Aguarde alguns segundos
