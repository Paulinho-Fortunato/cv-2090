# 🚀 Guia Rápido - Novas Funcionalidades

## 📊 Analytics Dashboard

**O que é:** Painel com estatísticas do seu uso do CV Builder

**Como acessar:**
1. No Builder, clique no ícone 📊 (canto superior)
2. Veja suas estatísticas

**O que mostra:**
- Total de currículos criados
- Total de downloads
- Score ATS médio
- Template mais usado
- Histórico dos últimos 10 downloads

---

## 🤖 Sugestões de IA

**O que é:** Análise inteligente do seu currículo com sugestões de melhoria

**Como usar:**
1. Clique em "Baixar PDF"
2. Clique em "Sugestões de IA"
3. Configure sua API Key (primeira vez)
4. Aguarde análise (5-10s)
5. Veja sugestões com ícones e cores

**Dica:** Obtenha API Key gratuita em https://makersuite.google.com/app/apikey

---

## 📝 Carta de Apresentação

**O que é:** Gerador automático de cartas personalizadas para vagas

**Como usar:**
1. Clique em "Baixar PDF"
2. Clique em "Carta de Apresentação"
3. Cole descrição da vaga
4. Escolha tom (Formal/Casual/Entusiasta)
5. Clique em "Gerar Carta"
6. Copie ou baixe como TXT

**Dica:** Use descrições completas para melhores resultados

---

## 📱 QR Code

**O que é:** QR Code com link para seu currículo online

**Como usar:**
1. Clique em "Baixar PDF"
2. Clique em "QR Code"
3. Baixe como PNG ou compartilhe

**Dica:** Adicione o QR Code em cartões de visita ou assinaturas de email

---

## ↩️ Undo/Redo

**O que é:** Desfazer/refazer alterações no currículo

**Como usar:**
- **Desfazer:** Ctrl+Z (Windows/Linux) ou Cmd+Z (Mac)
- **Refazer:** Ctrl+Y ou Cmd+Shift+Z

**Dica:** Até 50 ações podem ser desfeitas

---

## 🗜️ Compressão de Imagens

**O que é:** Compressão automática de fotos para PDF menor

**Como funciona:**
- Ativado automaticamente ao upload
- Reduz tamanho mantendo qualidade
- Máximo 500KB por imagem

**Dica:** Fotos comprimidas geram PDFs mais leves

---

## 📴 Modo Offline (PWA)

**O que é:** Funciona sem internet após primeiro acesso

**Como usar:**
1. Acesse o site uma vez com internet
2. Instale como app (opcional)
3. Use offline quando quiser

**Dica:** No Chrome, clique em "Instalar" na barra de endereço

---

## 🎯 Dicas Gerais

### Para Melhores Resultados

1. **Preencha tudo**
   - Quanto mais dados, melhor
   - Inclua todas as experiências
   - Liste skills relevantes

2. **Use IA com sabedoria**
   - Revise sugestões antes de aceitar
   - Mantenha autenticidade
   - Adapte ao seu estilo

3. **Teste templates**
   - Cada template tem estilo diferente
   - Escolha o que melhor representa você
   - Considere a vaga/empresa

4. **Otimize para ATS**
   - Use palavras-chave da vaga
   - Inclua métricas e números
   - Mantenha formatação simples

### Atalhos Úteis

- **Ctrl+Z** - Desfazer
- **Ctrl+Y** - Refazer
- **Ctrl+S** - Salvar (automático)
- **Ctrl+P** - Imprimir/Salvar PDF

### Privacidade

- ✅ Dados salvos apenas no seu navegador
- ✅ IA processa dados no Google (não nossos servidores)
- ✅ API Key armazenada localmente
- ❌ Não enviamos seus dados para terceiros

## 🆘 Problemas Comuns

### "IA não funciona"
- Verifique API Key
- Confirme conexão com internet
- Aguarde alguns segundos

### "PDF não baixa"
- Tente opção "Imprimir" (Ctrl+P)
- Verifique pop-ups bloqueados
- Use outro navegador

### "Foto não aparece"
- Verifique formato (JPG/PNG)
- Tamanho máximo: 5MB
- Tente outra foto

### "Dados sumiram"
- Verifique se está no mesmo navegador
- Não limpe cache/cookies
- Exporte JSON regularmente (backup)
